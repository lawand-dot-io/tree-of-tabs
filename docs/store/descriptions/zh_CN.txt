一眼就能看出每个标签页从哪里打开、哪些标签页属于同一组。标签页树会在您浏览时自动生成，始终与窗口顶部的标签页保持一致，看起来就像 Chrome 的一部分。

功能
• 自动嵌套：在新标签页中打开的链接、用鼠标中键点击打开的链接以及会打开标签页的网页，都会显示在来源标签页下方。您自己从地址栏、书签或新标签页打开的标签页会成为一棵新树。
• 拖放：将一个标签页拖到另一个标签页上即可嵌套，拖到两个标签页之间即可移动，拖到列表下方即可开始一棵新树。整个分支会随之移动。您还可以一次拖动多个选中的标签页，或将其移至另一个窗口。
• 与标签页始终同步：树和窗口顶部标签页的顺序始终一致。在顶部移动标签页时，其分支也会一起移动。
• 收起暂时不用的分支：将指针移到标签页上，其图标就会变成箭头。已收起的分支会显示其中的标签页数量。如果您从不收起，可以完全关闭收起功能。
• 关闭父标签页时分支不会散开：第一个子标签页会接替它的位置。您也可以选择将整个分支一起关闭。
• 已固定的标签页显示为顶部的一排图标。标签页分组会在其标签页旁边显示一条彩色线条。
• 拆分视图（并排的两个标签页）显示为一行并一起移动，因此树永远不会把它们分开。
• “新标签页”按钮：点击可开始一棵新树，点击鼠标中键或右键点击可在当前标签页下打开新标签页。
• 右键点击标签页即可执行快捷操作：在此分支中新建标签页、重新加载、复制、固定、静音、增加或减少缩进、将分支移至新窗口、关闭分支、关闭其他所有标签页或下方的标签页。
• 键盘友好：使用方向键在树中移动，按 Shift+F10 打开菜单，并使用键盘快捷键显示或隐藏标签页树（默认为 Alt+Shift+T，Mac 上为 Option+Shift+T）。
• 细细的辅助线会显示哪些标签页属于哪个父标签页，即使有多个层级也一目了然。如果您愿意，可以隐藏辅助线。
• 无论浅色模式还是深色模式，看起来都像浏览器的一部分。
• 全屏视频可以占满整个屏幕：网页进入全屏时，标签页树可以自动隐藏。
• 重启浏览器后仍会记住您的标签页树。
• 可选：从树中关闭最后一个标签页时保持窗口打开。
• 支持简体中文、Deutsch、English、Español、Français、Italiano、Português、Русский、Türkçe、日本語和 한국어。

使用方法
1. 点击工具栏中的 Tree of Tabs 按钮（或使用其键盘快捷键），即可在侧边栏中打开标签页树。
2. 照常浏览。从网页打开的标签页会显示在该网页下方。
3. 拖动标签页即可重新整理。右键点击标签页可执行更多操作。
4. 右键点击标签页树并选择“设置”，即可更改新标签页和已关闭标签页的行为、间距等。
Chrome 会为每个窗口分别打开侧边栏，因此在新窗口中，请使用工具栏按钮或键盘快捷键打开标签页树。
提示：如果想让标签页树显示在左侧，请打开 Chrome 的外观设置，将“侧边栏位置”设为“向左”。

隐私
Tree of Tabs 绝不会将您的标签页或浏览信息发送到任何地方。它只会将标签页树的结构保存在您自己的电脑上，以便在重启后恢复，并且没有任何分析、账号或服务器。如果您使用浏览器同步，您的设置会随浏览器个人资料同步。

权限
• “读取您的浏览记录”：Tree of Tabs 需要获取您打开的标签页的标题和地址，以便在树中显示它们，并了解新标签页是从哪个标签页打开的。它不会读取任何网页的内容，也看不到您已关闭网页的历史记录。
