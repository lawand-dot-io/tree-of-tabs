A small update.

- **About the side panel's width**: the settings page now explains that
  Chrome sets a minimum width for the side panel, which extensions can't
  change, and links to the
  [Chromium issue](https://issues.chromium.org/issues/40926440) where you can
  vote for a narrower one. In all 12 languages.

## Install

[Add Tree of Tabs to Chrome](https://chromewebstore.google.com/detail/tree-of-tabs/goknfcebnofoghkgcmpjhlokkgefbokm)
from the Chrome Web Store. If you already have it from the store, Chrome
updates it by itself.

To install it by hand instead, download `tree-of-tabs-v1.1.2.zip` below and
unzip it. Then open `chrome://extensions`, turn on Developer mode, click
**Load unpacked** and pick the unzipped folder. Needs Chrome 116 or newer.
