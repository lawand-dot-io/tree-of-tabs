Small improvements to Tree of Tabs.

- **A tip about new windows**: Chrome opens the side panel one window at a
  time, so a new window starts without the tree. The first time you open the
  tree with several windows open, the panel explains this and shows the
  keyboard shortcut.
- **The settings page** shows the Tree of Tabs icon next to its title.
- **A clearer description**: "Vertical tabs as a tree in the side panel."

## Install

[Add Tree of Tabs to Chrome](https://chromewebstore.google.com/detail/tree-of-tabs/goknfcebnofoghkgcmpjhlokkgefbokm)
from the Chrome Web Store. If you already have it from the store, Chrome
updates it by itself.

To install it by hand instead, download `tree-of-tabs-v1.0.1.zip` below and
unzip it. Then open `chrome://extensions`, turn on Developer mode, click
**Load unpacked** and pick the unzipped folder. Needs Chrome 116 or newer.
