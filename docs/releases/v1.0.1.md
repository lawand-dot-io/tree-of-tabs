Small improvements to Tree of Tabs.

- **A tip about new windows**: Chrome opens the side panel one window at a
  time, so a new window starts without the tree. The first time you open the
  tree with several windows open, the panel explains this and shows the
  keyboard shortcut.
- **The settings page** shows the Tree of Tabs icon next to its title.
- **A clearer description**: "Vertical tabs as a tree in the side panel."

Tree of Tabs is now on the Chrome Web Store:
[add it to Chrome](https://chromewebstore.google.com/detail/tree-of-tabs/goknfcebnofoghkgcmpjhlokkgefbokm). If you installed it from the
store, Chrome updates it by itself.
