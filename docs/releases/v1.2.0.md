Reopened tabs find their way home.

- **Ctrl+Shift+T puts tabs back in their place.** A tab you reopen goes back
  under the tab it was nested under, and its own children go back under it.
  Close a whole tree and press Ctrl+Shift+T a few times: it comes back
  together, the way it was.
- **A one-time request for a review.** After you've used Tree of Tabs for two
  weeks, on at least seven different days, a small note at the bottom of the
  tree asks whether you'd leave a review on the Chrome Web Store. Either
  button hides it for good, and it never comes back. The day count stays on
  your computer: see the [privacy policy](https://github.com/lawand-dot-io/tree-of-tabs/blob/main/PRIVACY.md).

## Install

[Add Tree of Tabs to Chrome](https://chromewebstore.google.com/detail/tree-of-tabs/goknfcebnofoghkgcmpjhlokkgefbokm)
from the Chrome Web Store. If you already have it from the store, Chrome
updates it by itself.

To install it by hand instead, download `tree-of-tabs-v1.2.0.zip` below and
unzip it. Then open `chrome://extensions`, turn on Developer mode, click
**Load unpacked** and pick the unzipped folder. Needs Chrome 116 or newer.
