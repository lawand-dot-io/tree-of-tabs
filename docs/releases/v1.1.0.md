Tree of Tabs now speaks your language.

- **11 languages**: English, German, Spanish, French, Italian, Japanese,
  Korean, Brazilian Portuguese, Russian, Turkish and Simplified Chinese. Tree
  of Tabs follows Chrome's language, and uses Chrome's own words for things
  like the side panel, pinning and closing tabs.
- **The settings page tip** now matches Chrome's current wording: set "Side
  panel position" to "Left" to show the tree on the left.

Found a translation that sounds off? Please
[report it](https://github.com/lawand-dot-io/tree-of-tabs/issues).

## Install

[Add Tree of Tabs to Chrome](https://chromewebstore.google.com/detail/tree-of-tabs/goknfcebnofoghkgcmpjhlokkgefbokm)
from the Chrome Web Store. If you already have it from the store, Chrome
updates it by itself.

To install it by hand instead, download `tree-of-tabs-v1.1.0.zip` below and
unzip it. Then open `chrome://extensions`, turn on Developer mode, click
**Load unpacked** and pick the unzipped folder. Needs Chrome 116 or newer.
