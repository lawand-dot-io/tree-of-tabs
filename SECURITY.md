# Security

If you find a security problem in Tree of Tabs, please report it privately by
email to **support@lawand.io** instead of opening a public issue. Include what
you found, how to reproduce it, and the version of Tree of Tabs and Chrome you
used.

You'll get a reply within a few days. Once a fix is published, the problem can
be discussed openly, with credit to you if you like.

Only the latest version, as published on the Chrome Web Store, gets security
fixes.
